Certificate Generator

Young Learners (Primary & Secondary) and Adult — Word templates → personalised PDF. Everything stays in your browser.

1 · Templates

Upload the Word templates once — they are remembered in this browser. Placeholders such as {{StudentName}} {{StudentID}} {{Course}} {{Term}} {{TeacherName}} {{AttendanceGrade}} {{ParticipationComment}} {{SpeakingComment}} {{ListeningComment}} {{ReadingComment}} {{WritingComment}} are filled in; any other data column can be used too (e.g. {{Class}}).

Young Learner templates (PP_01 … PP_06, PP_SA, PP_SB, LS-US …)
Adult templates

Level → template

Each level (the Event Type column) is matched to a template automatically. Change any row if needed — your choice is remembered. A Template column in the data overrides this.

2 · Young Learner student data

Paste straight from Excel, including the header row. Your current export works as-is:
Teaching Centre · Session · Class · Event Type · Student Number · Student Name · Teacher · Gender · Attendance · Speaking · Writing · Reading · Listening · Participation _ Effort
Mapping: Session → Term · Event Type → Level/Course · Student Number → Student ID · Teacher / Teacher 1 → Teacher. Paste Primary and Secondary together or separately (“Add” keeps what is already loaded).

3 · Comment bank

Paste columns Type · Gender · Subject · Grade · Comment from Excel (tab-separated). It is remembered in this browser.
• Type: Primary / Secondary (or an exact level such as Primary Plus 1, or All) — the most specific match wins.
• Gender: Male / Female · Subject: Participation, Speaking, Listening, Reading, Writing · Grade: as in the data, e.g. Strong 1, Medium 2, Weak 3.
Comments are used exactly as supplied — nothing is invented.

Adult student data

Paste from Excel with header row: StudentID Level Teacher StudentName Hours Month Year (optional Template column picks the template by file name; otherwise the first Adult template is used).
